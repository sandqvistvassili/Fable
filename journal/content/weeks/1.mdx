The surprise of the first week was not the programming. It was everything around the programming.

Writing `print("Hello")` took four seconds. Getting to the point where that line could run took two hours of PATH, versions, and learning to ask the computer what it thinks instead of guessing. The same pattern repeated all week: variables were easy, but reading my own code as instructions rather than intentions was not. Loops were easy, but knowing Ctrl-C exists was the actual lesson of the day.

One detour: I opened a web security lab on day 7, understood nothing, and stopped after forty minutes. Worth doing — the destination is real, and now I know exactly which floor of the building I am standing on.

Next week: dictionaries, and the first attempt at a program longer than ten lines.
