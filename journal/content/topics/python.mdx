Python is my first programming language. Not my first attempt at learning one — my first language that stuck, because this time every day of it is written down where anyone can see.

These entries are not tutorials. They are a record of what learning to program actually feels like from inside: installing Python and losing two hours to PATH before writing a single line, printing the wrong variable and reading my own code five times without seeing it, the first infinite loop and the small panic of not knowing how to stop it. If you are learning too, the value here is not my explanations — it is watching the same confusions you have happen to someone else, dated and numbered.

I chose Python deliberately. It is not tied to any one country's job market, it is the working language of the security field I am heading toward, and it gives a beginner something running on day one. The plan is boring on purpose: fundamentals first, no frameworks until the basics hold, and a review of the choice itself at day 180 — in public, like everything else here.

Start with the oldest entry below and read upward; the order is the point.
